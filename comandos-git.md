# Comandos de Git usados en esta práctica

| Comando | Para qué sirve |
|---|---|
| `git init` | Inicia un repositorio local |
| `git checkout -b feature-gabo` | Crea la rama y se cambia a ella |
| `git add <archivo>` | Prepara los cambios para el commit |
| `git commit -m "mensaje"` | Guarda los cambios con un mensaje |
| `git push -u origin feature-gabo` | Sube la rama a GitHub |
